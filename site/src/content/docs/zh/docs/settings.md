SpaceKnife 的设置都在一个「设置」标签页里。改动立即保存，没有「应用」按钮。这一页先讲设置页本身的用法，再按页列出每一项设置。

## 打开设置

- 按 <kbd>Ctrl</kbd>+<kbd>,</kbd>（macOS 上 <kbd>⌘</kbd>+<kbd>,</kbd>），点标题栏的「设置」按钮，或在[命令面板](../command-palette/)里运行「设置」。
- 设置标签页只有一个，已经打开时再按 <kbd>Ctrl</kbd>+<kbd>,</kbd> 会切回它。打开时显示上次看的那一页。
- 右下角的「完成」关闭设置，回到打开设置之前的标签。

左侧按三组列出各页：常规、外观、可视化；扫描与性能、文件类别、标签；快捷键、高级。<kbd>Backspace</kbd> 或 <kbd>Alt</kbd>+<kbd>←</kbd> 回到上一个看过的页，<kbd>Alt</kbd>+<kbd>→</kbd> 前进。

## 搜索设置

按 <kbd>/</kbd> 或 <kbd>Ctrl</kbd>+<kbd>F</kbd> 进入工具栏上的「搜索设置」。输入的文字在这些地方查找（不区分大小写，按包含匹配）：

- 设置的名称和说明；
- 所在的分组名和页名；
- 每个选项的名字和取值，例如搜 `1024` 找到「大小单位」；
- 每项设置的同义词，多是英文，例如 `mft`、`tooltip`、`uac`、`inotify`。英文界面里，设置的中文名也能搜到。

结果按「页 › 分组」列出，命中的文字高亮；左侧每页旁边显示命中数，没有命中的页变淡。在结果里可以直接修改。按 <kbd>Esc</kbd> 清空搜索，再按一次离开搜索框。

## 什么时候生效

大多数设置改了就生效。有两类例外，在设置下方用小字提示：

| 提示 | 含义 |
| --- | --- |
| 将在下一次扫描生效 | 扫描方式、扫描范围、硬链接计算这类设置，只在扫描进行中显示这条提示：正在进行的扫描不受影响 |
| 只影响之后新开的视图 | 「新视图…」「默认配色」这类设置：已经打开的视图保持原样 |

- 显示为灰色、带一个说明徽章的设置，在当前平台或当前版本不能修改，徽章写着原因。
- 依赖另一项的设置，在那一项满足条件前是灰色的，例如「手动并发数」只在「最大并发」选「手动」时能改。
- 与后端的连接断开时，页面顶部显示「与后端的连接已断开，设置暂不可修改」。
- 底部左侧显示保存状态：「更改已自动保存」「正在保存…」或「保存失败：…」。
- 数字框只接受范围内的整数，输错时提示「请输入 … 的整数」并恢复原值；滑块松开时保存；文字框按 <kbd>Enter</kbd> 或离开时保存，首尾空白去掉。

## 恢复默认

- **当前页**：底部的「恢复默认」把这一页所有能修改的设置恢复为默认值。鼠标停在按钮上会显示有几项会被恢复；这一页已经全是默认值时按钮不可用，搜索时也不可用。恢复后底部出现「已恢复「…」的默认值 · 撤销」，5 秒内点「撤销」可以还原。
- **全部**：「高级 › 导入与导出 › 全部恢复默认…」把所有设置和文件类别恢复为初始值，要再确认一次，不能撤销。

## 导入与导出

都在「高级 › 导入与导出」里。

**导出设置…** 把所有改过的设置和自定义的文件类别存成一个 JSON 文件，默认文件名带当天日期，例如 `SpaceKnife-设置-20261020.json`。只存与默认值不同的项。

**导入设置…** 读取这样一个文件，先列出会发生的变化，确认后才生效：

- 「将改变 N 项设置」：每一项的旧值 → 新值；
- 「文件类别将变为」：导入后的文件类别；
- 「不导入」：跳过的项和原因，例如来自其他版本的未知设置、不合法的值、当前版本不可修改的设置。

点「导入」生效，点「取消」什么都不改。注意导出文件只记录改过的项，所以导入时，文件里没有写的设置会恢复为默认值，预览里也会列出这些变化。更新版本 SpaceKnife 导出的文件（格式版本更高）不能导入。

**从 SpaceSniffer 导入** 读取 `SpaceSnifferConfig.xml`，把几何、动画、行为、外观和文件类别换算成对应的设置，同样先预览再确认。没有对应设置的部分（例如配色）列在「不导入」里，并写明原因。

## 直接编辑设置文件

设置保存在配置目录的 `settings.json` 里。左侧底部的「打开设置文件」用系统默认程序打开它，「高级 › 文件与诊断」显示它的完整路径。各个目录在哪里见[数据位置](../data-locations/)。

文件里只有与默认值不同的项，键就是下面参考表里的「设置键」：

```json
{
  "version": 1,
  "values": {
    "general.language": "en",
    "scan.load_manual": "quiet",
    "scan.unit_base": "1000",
    "treemap.initial_detail": 7,
    "tags.name_red": "待删除"
  }
}
```

- 类型要完全对上：开关写 `true` / `false`；滑块和数字框写范围内的整数（`7`，不是 `7.0` 或 `"7"`）；选项写参考表里列出的字符串，`"1024"` 和 `"60"` 也是字符串；文字最多 64 个字符。
- SpaceKnife 运行时也会读取对文件的修改，大约一秒内生效，打开着的设置页随之更新。
- 文件写错（不是合法的 JSON，或某个值不合法）时，设置页顶部显示「设置文件不合法，继续使用上一次的有效设置：…」，SpaceKnife 继续用上一次的有效设置，直到文件改对。
- 不认识的键被忽略。在设置页里再改任何一项时，文件会按当前设置重写，只留下与默认值不同的项。

:::tip
「强调色」在设置页里有四个色块可选，设置文件里可以写任意 `#RRGGBB` 颜色。
:::

「界面语言」也决定命令行输出的语言，见[命令行](../command-line/)。

## 各页的其他内容

有些页除了下面参考表里的设置，还有别的东西：

- **文件类别**：文件类别的编辑器，见[标签与文件类别](../tags-classes/)。
- **标签**：「已保存的标签 › 清除所有已保存的标签」显示有多少个扫描位置保存了标签，确认后全部清除。
- **快捷键**：「键位表」列出全部命令和它们的按键（没有按键的显示「未绑定」），键位表上方的「搜索命令或按键」可以按命令名或按键过滤，例如输入 `ctrl+` 列出所有带 Ctrl 的键。键位暂时不能修改，按键的完整说明见[快捷键](../shortcuts/)。
- **高级 › 扫描助手与缓存**：「扫描助手」显示它是否在运行、是否有管理员权限（MFT 快速扫描与 USN 日志由它读取），可以「停止扫描助手」；「快照」显示快照的个数、总大小和所在文件夹，可以打开它；「缓存」显示缓存的大小和位置，「清除缓存…」清除时保留正在使用的缓存。
- **高级 › 文件与诊断**：设置文件和日志文件夹的路径与「打开」按钮；「复制诊断信息」把版本、平台和后端信息复制到剪贴板，反馈问题时附上。
