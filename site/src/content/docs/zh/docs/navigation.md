每个视图都有自己的**缩放根**（铺满视图的那个文件夹）、自己的选中项和自己的前进后退历史。本页的操作在树图、火焰图和火焰-极坐标图里都一样（见[三种可视化](../visualizations/)），几乎每一项都有快捷键。

:::note[按键什么时候生效]
- 按键作用于**焦点视图**：分屏时是最后点过的那个窗格。
- 在输入框里打字时（过滤框、路径框、命令面板），单键快捷键（<kbd>V</kbd>、<kbd>C</kbd>、<kbd>F</kbd>、<kbd>U</kbd>、<kbd>1</kbd>–<kbd>4</kbd>、<kbd>0</kbd>、<kbd>/</kbd>、<kbd>Backspace</kbd> 等）不生效。
- 按钮或菜单项有焦点时，<kbd>Enter</kbd>、<kbd>Delete</kbd>、<kbd>Esc</kbd> 和 <kbd>Shift</kbd>+<kbd>F10</kbd> 留给它；下拉框有焦点时，<kbd>C</kbd> 和 <kbd>V</kbd> 留给它。点一下画面就恢复。
- macOS 上凡是写 <kbd>Ctrl</kbd> 的地方都可以按 <kbd>⌘</kbd>（按 <kbd>Ctrl</kbd> 也行），<kbd>Alt</kbd> 即 <kbd>Option</kbd>。
:::

## 放大与返回

**放大进入**让一个文件夹成为新的缩放根：它的内容铺满视图，这一步记入视图的历史。

| 方式 | 说明 |
|---|---|
| 双击文件夹 | 在它的标题栏或边框上，或在折叠块、条、扇区上双击 |
| 选中后按 <kbd>Enter</kbd> | 也就是命令面板里的「放大进入」 |
| 右键菜单 ›「只看这里（放大）」 | 同 <kbd>Enter</kbd> |
| 双击文件 | 放大进入它所在的文件夹，并选中这个文件 |
| 双击「N 个小项」或「+N 项」 | 把合并的项逐个铺开（见[小项聚合块](../visualizations/#小项聚合块)） |

可用空间和未知空间不能放大。

**返回**用下面的历史按键；也可以双击火焰图的根条或火焰-极坐标图的中心圆，回到上一级。

缩放带动画：双击的块长大到铺满视图，返回时再缩回原位。时长在「设置 › 可视化 › 缩放动画时长」调整（0–600 ms，默认 250，0 表示无动画）。开启「设置 › 外观 › 减少动画」后，缩放瞬时完成。

## 后退、前进、上一级、根

| 操作 | 按键 | 工具栏按钮 | 效果 |
|---|---|---|---|
| 后退 | <kbd>Backspace</kbd>、<kbd>Alt</kbd>+<kbd>←</kbd> | 「后退」 | 回到上一个缩放根，并恢复当时的选中项 |
| 前进 | <kbd>Shift</kbd>+<kbd>Backspace</kbd>、<kbd>Alt</kbd>+<kbd>→</kbd> | 「前进」 | 撤销一次后退 |
| 上一级 | <kbd>Alt</kbd>+<kbd>↑</kbd> | 「上一级」 | 缩放到父文件夹，并选中刚离开的那个文件夹 |
| 根 | <kbd>Ctrl</kbd>+<kbd>Home</kbd> | 「根」 | 回到扫描的顶层；整卷扫描时可用 / 未知空间重新出现 |

- 每个标签页、每个分屏窗格有独立的历史。上一级和根也记入历史，后退可以撤销它们。
- 已经在扫描顶层时，「上一级」和「根」不可用。
- 后退或前进时，已经不存在的位置（被删除，或重新扫描后消失）会被跳过。
- 切换可视化、配色或细节层级不记入历史：后退永远是「上一个位置」。

:::tip[上一级，再 Enter]
上一级会选中刚离开的文件夹，所以 <kbd>Alt</kbd>+<kbd>↑</kbd> 之后按 <kbd>Enter</kbd> 就回去了。可以先用 <kbd>Alt</kbd>+<kbd>↑</kbd> 看看同级的邻居，再按 <kbd>Backspace</kbd> 或 <kbd>Enter</kbd> 回来。
:::

## 面包屑与编辑路径

工具栏上的面包屑显示从扫描顶层到缩放根的路径。

- 单击前面的某一段，上到那一层。每一层算历史里的一步，后退时逐层退回。
- 整卷扫描时，第一段显示标签页的名称；在顶层时旁边标着「整个卷」。
- 放大进入聚合块后，最后一段是「N 个小项」或「+N 项」。
- 单击最后一段或按 <kbd>Ctrl</kbd>+<kbd>L</kbd> 编辑路径。完整路径会被选中，输入或粘贴另一个路径后按 <kbd>Enter</kbd>：文件夹成为缩放根，文件则打开它所在的文件夹并选中它。<kbd>Esc</kbd> 取消。路径不在扫描范围内时提示「路径不存在，或不在本次扫描范围内」。

分屏时每个窗格有自己的面包屑，可以单击返回上层。<kbd>Ctrl</kbd>+<kbd>L</kbd> 编辑的是工具栏上的面包屑，分屏时请在命令面板里输入路径（见[查找路径](#查找路径)）。

## 选中与详情面板

**单击**一个块即选中它；单击文件夹的标题栏、边框或内边距，选中的是这个文件夹。单击空白处或按 <kbd>Esc</kbd> 取消选中。右键单击也会先选中，再弹出菜单。

选中项按身份记住：视图重画、改层级、切换可视化、扫描更新画面时都保持不变。选中项被收进折叠块时，选中环画在它最近的可见祖先上。

选中的块带白色外环和柔和的投影（「选中投影」可以关掉投影），它的祖先会被点亮（「高亮光晕层数」，两项都在「设置 › 外观」）。

### 详情面板

右侧面板显示选中项；没有选中时显示缩放根。它有三个页签：

| 页签 | 内容 |
|---|---|
| 「详情」 | 名称和路径；大小，文件夹附带文件数、文件夹数和最近修改，文件附带类别和修改时间（悬停这一行可看精确字节数）；文件夹[按文件夹归类](../tags-classes/#按文件夹归类)时多一行，例如「整个文件夹算作「游戏」 · Steam 游戏库」；「占比」：占父文件夹、占所在卷已用空间的比例；文件夹还有「最大的子项」：它下面任意位置最大的五个文件；「标签」 |
| 「类别统计」 | 选中项按文件类别的构成：上面一条按类别配色的分段条，下面每个类别一行，写着文件数、大小、占比，配一条比例条，按大小排序。单击一行就按这一类过滤。「代码/开发」「数据/模型」占不到 2% 且不到 8 GB 时收起来，点「显示全部类别」展开。文件夹归类带进来的文件，悬停提示写明它们按扩展名本是什么，例如「其中按扩展名本是：视频 3.0 GB」。悬停一行或分段条的一段，左边的图就把这一类高亮出来：其余部分压暗，这一类的文件、以它为主的小项块和整个算作它的文件夹（比如游戏目录）保持原色、亮起一圈，只看选中的文件夹之内。移开就恢复，过滤不变 |
| 「最大文件」 | 它下面最大的文件，最多 50 个 |

单击「最大的子项」或「最大文件」里的文件即可**定位**：选中它；如果它没有画出来（太深或太小），视图会放大进入（记入历史），直到它出现。

底部是「在资源管理器中显示」（macOS 上为「在访达中显示」，Linux 上为「在文件管理器中显示」）、「复制路径」、「加入删除篮」三个操作，各自标着快捷键。「更多操作」按钮弹出右键菜单，等同 <kbd>Shift</kbd>+<kbd>F10</kbd>。「隐藏详情面板」把整个宽度让给画面，右侧边缘的「显示侧栏」再把它找回来。

拖动面板的左边缘可以调整宽度（280–640 像素，窗口窄时给画面至少留 360 像素），画面随之重新排布；双击左边缘恢复默认的 320 像素。宽度会被记住。也可以把焦点放到左边缘，用 <kbd>←</kbd> <kbd>→</kbd> 调整（按住 <kbd>Shift</kbd> 一次 64 像素）。

面板内容随操作变化：

- 过滤生效时显示「匹配结果」，即[匹配结果列表](#匹配结果列表)。
- 扫描进行中且没有选中项时显示「扫描详情」。
- 打开删除篮时显示删除篮。
- 选中聚合块、可用空间或未知空间时，说明这一块是什么。

### 选中项的按键

| 按键 | 作用 |
|---|---|
| <kbd>Enter</kbd> | 放大进入 |
| <kbd>Esc</kbd> | 取消选中（对比视图里没有选中项时：退出对比） |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | 复制路径 |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | 在资源管理器 / 访达 / 文件管理器中显示 |
| <kbd>Ctrl</kbd>+<kbd>`</kbd> | 在文件夹里打开终端（文件则在它所在的文件夹） |
| <kbd>Delete</kbd> | 加入删除篮 |
| <kbd>1</kbd>–<kbd>4</kbd> 或 <kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>4</kbd> | 红、黄、绿、蓝标签 |
| <kbd>0</kbd> 或 <kbd>Ctrl</kbd>+<kbd>0</kbd> | 清除这一项及其下所有标签 |
| <kbd>Shift</kbd>+<kbd>F10</kbd>、菜单键 | 弹出右键菜单 |

<kbd>Delete</kbd> 只是把它放进删除篮，在删除篮里执行之前，磁盘上什么都不会删（见[清理空间](../cleanup/)）。不带 <kbd>Ctrl</kbd> 的标签键可以在「设置 › 标签 › 树图有焦点时可省略 Ctrl」关闭；更多见[标签与文件类别](../tags-classes/)。

## 悬停卡

指针在块上停一会儿，旁边就出现一张卡片，位置会避开这个块。卡片显示：

- 名称和所在文件夹；
- 大小和它占父文件夹的比例；
- 文件夹显示文件数和文件夹数，文件显示类别和扩展名；
- 「创建」「修改」「访问」时间，以及距今多久。

卡片打开后，移到另一个块时内容直接换成新的。「设置 › 常规 › 悬停提示」里的三个开关控制它：「切换元素时保持打开」「显示日期与时间」「显示文件年龄」。

- 火焰-极坐标图里卡片跟随指针。
- 缩放动画进行中不显示卡片。
- 「设置 › 外观」里的「悬停高亮」给指针下的块画一圈细白描边；「鼠标拖尾」让指针划过的块留下渐隐的描边。
- 悬停匹配结果列表里的一行，画面上对应的块也会这样高亮。

## 右键菜单

右键单击块、条或扇区弹出它的菜单，它会先被选中。用键盘时，<kbd>Shift</kbd>+<kbd>F10</kbd> 或菜单键弹出选中项的菜单，位置在它旁边。两种火焰图里没有选中项时，弹出的是缩放根（根条或中心圆）的菜单；树图里需要先选中。

菜单顶部是一行概要（名称、大小、类型、所在文件夹），下面是：

| 项 | 按键 | 作用 |
|---|---|---|
| 「打开」 | | 用默认程序打开文件，或打开文件夹 |
| 「在资源管理器中显示」（访达、文件管理器） | <kbd>Ctrl</kbd>+<kbd>E</kbd> | 在系统的文件管理器里显示 |
| 「在此打开终端」 | <kbd>Ctrl</kbd>+<kbd>`</kbd> | 在文件夹里打开终端，文件则在它所在的文件夹 |
| 「复制路径」▸ | | 「原样」（<kbd>Ctrl</kbd>+<kbd>C</kbd>）、「带引号」、「POSIX 路径」、「file:// URI」，每一项都有预览 |
| 「加标签」▸ | | 「红色标签」「黄色标签」「绿色标签」「蓝色标签」（<kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>4</kbd>）、「清除标签」（<kbd>Ctrl</kbd>+<kbd>0</kbd>） |
| 「只看这里（放大）」 | <kbd>Enter</kbd> | 放大进入 |
| 「归类」▸（仅文件夹） | | 「自动识别」「只按扩展名」，或「算作「<类别>」」：整个文件夹里的文件都算这一类，见[按文件夹归类](../tags-classes/#按文件夹归类) |
| 「重新扫描此文件夹」 | | 把这个文件夹连同下面的一切重新读一遍（文件则是它所在的文件夹） |
| 「加入删除篮」 | <kbd>Delete</kbd> | 放进删除篮 |
| 「系统菜单…」 | | 已列出，暂不可用 |

菜单里的按键：

| 按键 | 作用 |
|---|---|
| <kbd>↑</kbd> / <kbd>↓</kbd> | 移动 |
| 在「复制路径」「加标签」「归类」上按 <kbd>→</kbd> 或 <kbd>Enter</kbd> | 打开子菜单 |
| <kbd>←</kbd> | 关闭子菜单 |
| <kbd>Enter</kbd> | 执行当前项 |
| <kbd>Esc</kbd> | 先关子菜单，再关菜单 |

暂时不能用的项仍留在菜单里，悬停或选择它就能看到原因，比如聚合块没有一个具体位置可以打开或复制。单击别处、调整窗口大小或切换到其他程序时菜单关闭。根条和中心圆的菜单里没有「只看这里（放大）」，因为它已经是缩放根。

## 分屏

分屏把同一次扫描的两个视图并排显示。用工具栏的「分屏」按钮或命令面板里的「分屏」打开；再用一次回到单视图（保留焦点窗格）。

- 新窗格从扫描顶层开始，沿用焦点窗格的可视化、配色、细节层级和可用 / 未知空间开关。
- 之后每个窗格各有自己的缩放、历史、选中项、过滤、可视化和层级。
- 每个窗格有一行标题：自己的面包屑（单击某一段返回上层）、大小、过滤时的匹配数、自己的过滤框，以及关闭按钮（「关闭左窗格」「关闭右窗格」）。关掉一个，另一个占满整个区域。
- 在窗格里单击即让它获得焦点，它的标题会高亮。工具栏、按键和详情面板都跟随焦点窗格。
- 快照对比时不能分屏。

用法举例：同一个位置一边树图、一边火焰图；左边整个磁盘，右边一个很深的文件夹；同一片区域，一边过滤、一边不过滤。

## 标签页

每次扫描在标题栏里有自己的标签页。名称后面显示扫描状态（「· 扫描中」「· 已暂停」「· 未完成」「· 扫描失败」），悬停提示显示文件系统和容量。

| 按键 | 作用 |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>T</kbd> | 新建标签，打开启动页（「新扫描」） |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | 关闭标签；中键单击标签或点它的 × 也一样 |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd>、<kbd>Ctrl</kbd>+<kbd>PageDown</kbd> | 下一个标签 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd>、<kbd>Ctrl</kbd>+<kbd>PageUp</kbd> | 上一个标签 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>PageUp</kbd> / <kbd>PageDown</kbd> | 把当前标签左移 / 右移一位 |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | 设置 |

- 切换标签首尾循环。
- 按住标签左右拖动可以调整顺序：指针越过相邻标签的中线，就和它换位。拖动中按 <kbd>Esc</kbd> 恢复原来的顺序。用按键移动标签到两端为止，不循环。
- 关闭仍在扫描的标签会停止那次扫描。关掉最后一个标签后，会留下一个空的「新扫描」标签。
- 设置也是一个标签，而且只有一个。在设置里，<kbd>/</kbd> 或 <kbd>Ctrl</kbd>+<kbd>F</kbd> 跳到设置搜索框，<kbd>Backspace</kbd> / <kbd>Alt</kbd>+<kbd>←</kbd> 和 <kbd>Alt</kbd>+<kbd>→</kbd> 在看过的设置页之间后退、前进。

## 匹配结果列表

过滤生效时（<kbd>/</kbd> 或 <kbd>Ctrl</kbd>+<kbd>F</kbd>，见[过滤](../filtering/)），详情面板变成「匹配结果」：匹配项的总大小和数量、占已扫描的比例、过滤的条件，以及一个列表。

列表跟着画面走，只包括缩放根以下的内容：

- 单独画出的匹配文件，一项一行；
- 藏在折叠块或聚合块里的匹配项，归到那一块的行里，并标出项数；
- 落在小到画不出来的块里的匹配项，合成最后一行「其余 N 项」。

所以各行加起来正好是总数。列表显示「当前位置下没有匹配项」时，按 <kbd>Alt</kbd>+<kbd>↑</kbd> 到上一级，在更大的范围里找。用顶部的菜单按「按大小」「按名称」「按项数」排序。

| 鼠标或按键 | 作用 |
|---|---|
| 悬停一行 | 在画面上高亮它的块 |
| 单击 | 定位：选中它，需要时放大进入 |
| 双击、<kbd>Enter</kbd> | 放大进入 |
| 右键 | 弹出这一块的右键菜单 |
| <kbd>↑</kbd> / <kbd>↓</kbd>、<kbd>Home</kbd> / <kbd>End</kbd>、<kbd>PageUp</kbd> / <kbd>PageDown</kbd> | 在列表里移动，并依次高亮对应的块 |
| <kbd>Space</kbd> | 定位当前行 |
| <kbd>Delete</kbd> | 把文件或文件夹加入删除篮 |

带 <kbd>Alt</kbd> 或 <kbd>Ctrl</kbd> 的按键仍交给视图处理，所以列表有焦点时 <kbd>Alt</kbd>+<kbd>↑</kbd>、<kbd>Ctrl</kbd>+<kbd>Home</kbd> 照样有效。

:::tip[逐个过一遍匹配项]
过滤后单击第一行，然后一直按 <kbd>↓</kbd>：每个匹配项依次在画面上亮起。按 <kbd>Space</kbd> 选中，按 <kbd>Delete</kbd> 收进删除篮，接着往下看。
:::

## 查找路径

命令面板（<kbd>Ctrl</kbd>+<kbd>K</kbd>）能找到扫描里的任何文件和文件夹，全部用法见[命令面板](../command-palette/)。

- **按名称**：输入名称的一部分。完全同名的排在最前，其次是以它开头的、包含它的、按顺序含有这些字母的；每一组里大的在前。在结果上按 <kbd>Enter</kbd> 跳过去：文件夹成为缩放根，文件则打开它所在的文件夹并选中它。
- **按路径**：输入 `C:\Users\lenny\Videos`、`/home/lenny/Videos` 或以 `~` 开头的路径，第一行是「跳转到」这个路径。输入以分隔符结尾的文件夹路径，面板列出它里面的内容；<kbd>Tab</kbd> 把当前行补全到输入框，可以一层层往下走。不在扫描范围内的路径会给出「扫描此位置」。
- **找同名项**：选中某一项后打开命令面板，输入框留空，「路径」组列出名称包含它的名称的其他项，最多五个（「匹配选中项「…」」）。选中一个 `node_modules`，其他的马上就出来了。

跳转过的位置下次会出现在「最近」里。

## 本页全部按键

| 按键 | 作用 |
|---|---|
| 双击、<kbd>Enter</kbd> | 放大进入 |
| <kbd>Backspace</kbd>、<kbd>Alt</kbd>+<kbd>←</kbd> | 后退 |
| <kbd>Shift</kbd>+<kbd>Backspace</kbd>、<kbd>Alt</kbd>+<kbd>→</kbd> | 前进 |
| <kbd>Alt</kbd>+<kbd>↑</kbd> | 上一级 |
| <kbd>Ctrl</kbd>+<kbd>Home</kbd> | 根 |
| <kbd>Ctrl</kbd>+<kbd>L</kbd> | 编辑路径 |
| <kbd>/</kbd>、<kbd>Ctrl</kbd>+<kbd>F</kbd> | 聚焦过滤 |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | 命令面板 |
| <kbd>Esc</kbd> | 取消选中 |
| <kbd>Shift</kbd>+<kbd>F10</kbd>、菜单键 | 右键菜单 |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>E</kbd> / <kbd>Ctrl</kbd>+<kbd>`</kbd> | 复制路径 / 在文件管理器中显示 / 打开终端 |
| <kbd>Delete</kbd> | 加入删除篮 |
| <kbd>1</kbd>–<kbd>4</kbd>、<kbd>0</kbd>（带不带 <kbd>Ctrl</kbd> 都行） | 加标签、清除标签 |
| <kbd>Ctrl</kbd>+<kbd>T</kbd> / <kbd>Ctrl</kbd>+<kbd>W</kbd> | 新建标签 / 关闭标签 |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> | 下一个 / 上一个标签 |
| <kbd>Ctrl</kbd>+<kbd>PageDown</kbd> / <kbd>Ctrl</kbd>+<kbd>PageUp</kbd> | 下一个 / 上一个标签 |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | 设置 |

可视化本身的按键（<kbd>V</kbd>、<kbd>C</kbd>、<kbd>F</kbd>、<kbd>U</kbd>、细节层级）见[三种可视化](../visualizations/#本页按键)；全部按键见[快捷键](../shortcuts/)。
