SpaceKnife 让你看清磁盘被什么占满了。它扫描一个磁盘或文件夹，把里面的一切画成一幅「大小即空间」的图，最大的文件和文件夹一眼就能看出来。扫描进行中画面边扫边填，扫描结束后继续跟上磁盘上的变化。

支持 Windows 10 及以上、Linux 和 macOS 14 及以上，界面有简体中文和英文。

## 能做什么

- **三种可视化**：同一次扫描可以画成嵌套树图、火焰图或火焰-极坐标图，随时按 <kbd>V</kbd> 切换。
- **扫描快**：并行读取文件夹。在 Windows 上，整个 NTFS 卷还可以直接读取主文件表（MFT），几秒内完成。
- **不抢磁盘**：可以限制扫描造成的磁盘负载，其他程序需要磁盘时扫描会主动让路。
- **实时监控**：扫描结束后，磁盘上的变化持续更新进来，变化的块会闪烁。
- **过滤**：按名称、文件类别、大小、日期、属性和标签过滤，可以自由组合。匹配项保持原样，其余暗化，侧栏列出全部匹配项。
- **标签**：四种颜色标签（红 ▲、黄 ■、绿 ●、蓝 ◆），标记要保留或要清理的东西。
- **快照与对比**：每次扫描后自动保存快照。任意两份之间、或快照与现在之间都能对比，看出什么变大了、什么是新出现的。
- **安全清理**：先把要删的东西收进删除篮。默认移到回收站，系统文件夹受保护。
- **导出与命令行**：导出 CSV、JSON、HTML 报告；命令行可以扫描和管理快照。

## 从哪里开始

1. [安装与升级](./install/)：把 SpaceKnife 装到你的系统上。
2. [第一次扫描](./first-scan/)：选一个磁盘或文件夹，读懂结果。
3. [三种可视化](./visualizations/)：树图、火焰图、火焰-极坐标图各自表示什么，配色、细节层级和特殊块。
4. [浏览与导航](./navigation/)：放大、历史、详情面板、右键菜单、分屏和标签页。
5. [过滤](./filtering/)：精确找到你关心的文件。
6. [快捷键](./shortcuts/)：全部按键一页看完。

第一次扫描之后如果只读一页，就读[浏览与导航](./navigation/)：那里几乎每个操作都有快捷键，用熟了按键，SpaceKnife 才真正快起来。

## 先记住这些快捷键

| 按键 | 作用 |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | 命令面板：执行命令、跳转路径、按名称找文件、套用过滤 |
| 双击、<kbd>Enter</kbd> | 放大进入文件夹 |
| <kbd>Backspace</kbd> | 后退到刚才的位置 |
| <kbd>Alt</kbd>+<kbd>↑</kbd> | 上一级 |
| <kbd>Ctrl</kbd>+<kbd>Home</kbd> | 回到扫描顶层 |
| <kbd>/</kbd> 或 <kbd>Ctrl</kbd>+<kbd>F</kbd> | 过滤 |
| <kbd>V</kbd> / <kbd>Shift</kbd>+<kbd>V</kbd> | 下一种 / 上一种可视化 |
| <kbd>C</kbd> | 下一种配色 |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | 多画 / 少画一层细节 |
| <kbd>F</kbd> / <kbd>U</kbd> | 显示或隐藏可用空间 / 未知空间 |
| <kbd>Shift</kbd>+<kbd>F10</kbd> | 选中项的右键菜单 |
| <kbd>Delete</kbd> | 把选中项放进删除篮（这时还没有删除任何东西） |
| <kbd>Ctrl</kbd>+<kbd>T</kbd> / <kbd>Ctrl</kbd>+<kbd>W</kbd> | 新建标签 / 关闭标签 |

在输入框里打字时单键快捷键不生效。macOS 上凡是写 <kbd>Ctrl</kbd> 的地方都可以按 <kbd>⌘</kbd>，<kbd>Alt</kbd> 即 <kbd>Option</kbd>。完整列表见[快捷键](./shortcuts/)。

## 几个值得养成的习惯

- **放大，而不是眯眼看。** 细节层级保持适中，双击进入你关心的部分；<kbd>Backspace</kbd> 让你回到原来的位置，连选中项都一样。
- **让侧栏替你读数。** 选中一个文件夹，打开「最大文件」，它下面最大的文件不管藏在哪里都会列出来。
- **找出同名的一批。** 选中一个 `node_modules` 之类的文件夹，按 <kbd>Ctrl</kbd>+<kbd>K</kbd>，输入框留空：命令面板列出名称包含它的其他项。
- **两个视图一起看。** 分屏把同一次扫描的树图和火焰图并排放在一起。
- **先过滤，再逐个看。** 过滤后单击侧栏里的第一个匹配项，然后按 <kbd>↓</kbd>：每个匹配项依次在画面上亮起。
