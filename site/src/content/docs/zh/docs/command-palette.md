命令面板是一个输入框，同时搜索四样东西：命令、本次扫描里的文件和文件夹、你输入的路径、你输入的过滤条件。熟悉它以后，大部分操作都不用找按钮。

## 打开与关闭

- 按 <kbd>Ctrl</kbd>+<kbd>K</kbd>（macOS 上 <kbd>⌘</kbd>+<kbd>K</kbd>），或点工具栏上的「命令面板」按钮。启动页、扫描视图、设置都能打开，焦点在过滤框里时也可以；但在启动页的路径框、编辑路径的输入框，以及设置里的搜索框、数字框和标签名称框中输入时不行。
- 关闭：<kbd>Esc</kbd>、再按一次 <kbd>Ctrl</kbd>+<kbd>K</kbd>、点面板外面，或者执行任意一行。关闭后焦点回到打开前的位置，输入的内容不保留。
- 面板打开时，背后的界面不响应鼠标和键盘，但实时监控带来的刷新照常进行。

在扫描标签里，输入框右端显示这个标签的扫描目标，提示面板作用于这个扫描：按名称找文件、过滤预览、「重新扫描当前视图」等都针对它。分屏时，作用于焦点窗格的视图。

## 输入什么，得到什么

| 输入 | 面板列出 |
| --- | --- |
| 什么都不输入 | 「最近」（最多 5 条）、9 条常用命令；有选中项时，还有名字包含选中项名称的其他项 |
| 命令名、拼音或英文词，例如 `cxsm`、`rescan` | 匹配的命令（最多 20 条），以及本次扫描里名称匹配的文件和文件夹 |
| 以盘符、`\\`、`/` 或 `~` 开头的路径 | 第一行「跳转到」这个路径，下面是这个文件夹里的子项 |
| 带 `*`、`?`、`;`、`\|`、`<`、`>`、`:`、`"` 或以单个 `\` 开头 | 第一行「过滤」这个条件和实时统计，下面是名称符合这个通配符的文件和文件夹 |

结果分组显示，顺序固定：直达的一行（跳转或过滤）、「最近」、「命令」、「路径」。没有内容的组整组隐藏，什么都没找到时显示「没有匹配的命令或路径」。

## 键盘

| 按键 | 作用 |
| --- | --- |
| <kbd>↑</kbd>、<kbd>↓</kbd> | 移动高亮，到头后从另一端继续 |
| <kbd>PageUp</kbd>、<kbd>PageDown</kbd> | 一次移动 10 行 |
| <kbd>Enter</kbd> | 执行高亮的一行 |
| <kbd>Tab</kbd> | 补全，见下文 |
| <kbd>Esc</kbd> | 关闭 |

- 打开或改了输入后，高亮落在第一行能执行的结果上，所以通常输完直接按 <kbd>Enter</kbd> 就行。
- 结果还没算出来就按了 <kbd>Enter</kbd>，面板会等这次输入的结果到了再执行第一行能执行的结果（依次看直达行、最近、命令），不会执行上一次输入留下的旧结果。
- 鼠标移到一行上就高亮它，单击执行。
- 用中文输入法组字时，<kbd>Enter</kbd>、方向键和 <kbd>Esc</kbd> 交给输入法：先上屏，再执行。

<kbd>Tab</kbd> 按高亮的那一行补全：

| 高亮的是 | <kbd>Tab</kbd> 的效果 |
| --- | --- |
| 命令 | 把命令名填进输入框 |
| 路径（跳转行或「路径」组） | 补全路径；文件夹带结尾的分隔符，可以接着输入或再按 <kbd>Tab</kbd> |
| 过滤 | 补全光标所在的词，和过滤框的补全一样 |
| 最近的一条 | 把它填进输入框；文件夹带结尾的分隔符 |

## 搜索命令

输入的字母只要按顺序出现在命令名里就算匹配，不必相连，空格忽略。连续命中、词首命中和开头命中排得更靠前，完全相同和前缀相同的排最前。命中的字在结果里加粗显示。

一条命令可以用这些方式找到：

- **中文名**：`配色`、`快照`。
- **全拼和拼音首字母**：`chongxin` 或 `cxsm` 找到「重新扫描当前视图」，`qhps` 找到「切换配色」，`fd` 找到「放大进入」。
- **英文别名**：`rescan`、`tag`、`snap`、`terminal`。每条命令的别名列在[快捷键](../shortcuts/)页末尾的表里。
- 英文界面里，先按英文名搜索；中文名、拼音和别名照样有效。

同样程度的命中，名字本身优先于拼音，拼音优先于别名。

### 只在输入时出现的命令

「配色：文件类别」「配色：扁平」「配色：修改时间」「配色：顶层分支」和「可视化：树图」「可视化：火焰图」「可视化：火焰-极坐标图」不出现在空输入的列表里，也不在设置的键位表里。输入 `配色`、`peise`、`color flat` 或 `treemap` 这类词时才列出，直接选定一种配色或可视化，而不是像 <kbd>C</kbd>、<kbd>V</kbd> 那样轮换。

### 空输入时的 9 条命令

什么都不输入时，「命令」组固定列出：重新扫描当前视图、全盘重新扫描、切换配色、显示/隐藏可用空间、打开删除篮、保存快照、与快照对比…、导出报告…、设置。顺序和内容是固定的，不能自定义。每行右端是它的按键，所以这一组也是一张速查表。

### 状态和不可用的原因

命令名后面的灰字是它的当前状态，打开面板时算出来；扫描进行中每 2 秒刷新一次。例如：

| 命令 | 状态 |
| --- | --- |
| 全盘重新扫描 | 当前这次扫描用的方式，「MFT 快速扫描」或「硬扫描」；扫描完成后加上它用的时间，如「MFT 快速扫描 · 约 5 秒」 |
| 切换配色、切换可视化 | 「当前：文件类别」「当前：树图」 |
| 显示/隐藏可用空间、显示/隐藏未知空间 | 「当前：显示」或「当前：隐藏」 |
| 打开删除篮 | 删除篮里的项数，或「空」 |
| 与快照对比… | 这个扫描目标已有的快照数，如「3 个快照」 |
| 导出报告… | 「CSV · JSON · HTML」 |
| 检查更新 | 「正在检查…」「有新版本 …」或「当前版本 …」 |
| 配色：…、可视化：… | 正在用的那一种显示「当前」 |

现在不能执行的命令显示为灰色，灰字换成原因，按 <kbd>Enter</kbd> 不会执行。常见的原因：

| 原因 | 说明 |
| --- | --- |
| 需要先完成扫描 | 这个标签还没有扫描结果（例如在启动页或设置里） |
| 扫描进行中 | 要等扫描结束，例如重新扫描、保存快照 |
| 没有进行中的扫描、扫描没有暂停、已暂停 | 暂停、继续、停止扫描的前提不满足 |
| MFT 快速扫描几秒内完成，无需暂停 | MFT 快速扫描不能暂停 |
| 没有可以继续的扫描 | 「继续已停止的扫描」只用于停止时还有文件夹没读完的硬扫描 |
| 没有选中项 | 放大、复制路径、标签等需要先选中一个块 |
| 没有可后退的位置、没有可前进的位置、已经在根 | 导航到头了 |
| 没有快照 | 这个位置还没有保存过快照 |
| 这种可视化在当前界面不可用 | 当前窗口或快照对比里不能显示这种可视化 |
| 没有可用的更新 | 「查看更新」只在发现新版本后可用 |

名称以「…」结尾的命令还要再选一步：「与快照对比…」选快照，「导出报告…」打开导出对话框，「打开快照文件…」选文件。「预览」（<kbd>Space</kbd>）还没有实现，在面板里显示为不可用。

## 按名称找文件和文件夹

在扫描标签里输入不是路径也不是过滤条件的文字时，「路径」组在整个扫描里按名称搜索：

1. 名称完全相同
2. 名称以输入开头
3. 名称包含输入
4. 输入的字母按顺序散落在名称里（只对 3 个及以上字符的输入；中文等非英文字母的输入从 2 个字起）

每一档里大的在前。英文字母不分大小写。最多列出 50 项，组标题显示「显示 50 / 总数」。每行是名称（命中的字加粗）、所在文件夹和大小；<kbd>Enter</kbd> 放大到它，文件则放大到它所在的文件夹并选中它。

- 输入里有 `*` 或 `?` 时，名称按通配符匹配，规则和过滤里的名称条件相同，同时第一行出现对应的「过滤」。
- 扫描还没完成时，组标题提示「扫描未完成，结果可能不全」。
- 已经删除的项不会出现。

:::tip[找同名的文件]
先在画面里选中一个文件或文件夹，再按 <kbd>Ctrl</kbd>+<kbd>K</kbd>、什么都不输入：「路径」组标题是「匹配选中项「名称」」，列出扫描里名字等于或包含这个名称的其他项（最多 5 项）。散落在各处的副本、同名的缓存文件夹一眼就能看到。
:::

## 跳转到路径

以盘符（`C:`、`D:\`）、`\\`（网络路径）、`/` 或 `~`（主目录）开头的输入当作路径。Windows 上 `/` 也可以当分隔符。

第一行「跳转到」显示这个路径的情况：

| 情况 | 显示 | <kbd>Enter</kbd> |
| --- | --- | --- |
| 在本次扫描里 | 右端是它的大小 | 放大到它；文件则放大到所在文件夹并选中 |
| 在磁盘上，但不在本次扫描范围内 | 「不在当前扫描范围内」和「扫描此位置」 | 新开一个标签扫描这个位置。在启动页和设置里输入路径也是这样 |
| 不存在 | 「路径不存在」 | 不能执行 |

下面的「路径」组列出这个文件夹里的子项：按最后一段已输入的文字匹配（开头相同、包含、字母散落），没有输入最后一段时按大小列出最大的几项。

<kbd>Tab</kbd> 一次补全一段：在已输入的文件夹里找以最后一段开头的项，文件夹优先、大的优先，文件夹补上结尾的分隔符。连续按 <kbd>Tab</kbd> 就能一层层往下走：

```text
C:\Users\lenny\Vi      → Tab → C:\Users\lenny\Videos\
~/Down                 → Tab → /home/lenny/Downloads/
```

本次扫描里有的路径按扫描结果补全；扫描范围外的路径按磁盘上的实际内容补全。

## 套用过滤

输入里有过滤语法的字符时，第一行是「过滤」：条件按过滤框的规则着色，右端是它在当前扫描上实时算出的「N 项 · 合计大小」。条件有错误时用红字显示错误，这一行不能执行。

按 <kbd>Enter</kbd> 把条件写进焦点视图的过滤框并立即生效，和在过滤框里输入一样。例如：

```text
*.iso;>1gb
:class:视频;>500mb
```

过滤语法见[过滤](../filtering/)。

## 最近

面板记住你在面板里执行过的两类操作：跳转到某个路径、套用某个过滤。

- 同一项再执行一次就移到最前，不重复。
- 跳转按扫描目标分别记录，过滤记录所有扫描共用。
- 重启后还在；每类最多保留 50 条，空输入时显示最近 5 条。输入文字时，匹配的最近记录也会列出。
- 跳转的路径在当前扫描里已经不存在时，显示「已不存在」，不能执行。过滤记录右端的统计按当前扫描实时计算。
- 「最近」标题右侧的「清除」立即清空当前扫描目标的跳转记录和全部过滤记录，不再确认。

最近记录只在扫描标签里能执行。

## 进阶用法举例

| 想做什么 | 输入 |
| --- | --- |
| 扫描一个新位置 | `~/Downloads` 或 `D:\Games`，<kbd>Enter</kbd>（不在当前扫描里时选「扫描此位置」） |
| 看某个文件夹里最大的几项 | `C:\Users\lenny\`，不输入最后一段 |
| 快速套用过滤并先看结果 | `*.iso;>1gb`，看右端的「N 项 · 合计大小」，再 <kbd>Enter</kbd> |
| 直接切到某种配色 | `peise` 或 `color time`，选「配色：修改时间」 |
| 按名称找一个大文件夹 | `node_modules`，按大小排在前面的就是最大的几个 |
| 重新扫描当前缩放的文件夹 | `cxsm` 或 `rescan`，选「重新扫描当前视图」 |

全部命令和按键见[快捷键](../shortcuts/)。
